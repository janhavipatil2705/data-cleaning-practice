# 🧹 Data Cleaning Practice

This repository contains my **data cleaning and preprocessing practice projects** while learning Data Analytics with Python and Pandas.

Instead of keeping each practice exercise in a separate repository, I use this repository to organize my learning progress through multiple datasets and data-cleaning exercises.

## 🎯 Purpose

The main goal of this repository is to practice how to identify, understand, and fix common data-quality problems before performing data analysis.

Through these exercises, I am practicing:

* 🔍 Data exploration
* ❌ Handling missing values
* 🔄 Removing duplicates
* ✂️ Cleaning and standardizing text
* 🔢 Correcting data types
* 📅 Working with date and time data
* 📊 Handling inconsistent categorical values
* ⚠️ Identifying invalid or unusual values
* 🧮 Handling numerical data
* 🐼 Using Pandas for data cleaning and preprocessing
